视觉单点共模防护（本次设计核心）
Qwen 既是图的生产者（T3 编码画图）又是检查者（视觉官）——错误可能被「确认」而非「检出」。三道防线： ① OCR 双读取头：Qwen vision + PaddleOCR（非 LLM），关键字段两读不一致 → 升级人工/重渲染； ② 程序化渲染断言（零 LLM）：字体嵌入检查 / 像素非空率 / 文字区域检测——豆腐块、空图不经过任何模型判断； ③ 种子缺陷图注入回归：已知缺陷图库注入视觉检查，漏报即阻断（与检测层种子库同构）。
双头同漏 ≤1/20 · 断言检出率 100%
↩
视觉失败回退（显式代价）
Qwen 视觉官失败 → 重试 ≤2 次 → 人工介入。K3 视觉零调用 = 视觉无模型回退——这是成本指令的显式代价，写进设计而非默认。
重试×2 → 人工
