## 1. 视觉任务硬路由（全 Qwen，无例外）

路由层硬编码以下任务 → Qwen 视觉官（vision_analyze 已切 custom/qwen3.8-max/DashScope compatible-mode，2026-08-14 落地）：

| 视觉职责 | 说明 |
|---|---|
| vision_analyze 视觉核查 | 架构图/图表/页面逐块分析 |
| UI 设计 | 页面/图表设计迭代 |
| 图表渲染检查 | 像素级检查（缺字体/豆腐块/空图/线重叠） |
| OCR | 扫描件/图内文字提取 |
| 页面验收 | 交付物视觉验收 |
| 图内文字提取 | 评委 D 组「图内文字-题注一致性」前置输入（数模侧衔接） |

**硬约束 A1**：K3 视觉调用 = 0（30 天全链路日志审计验证）。K3 剩余职责仅一项：**低频高价值推理审查**（设计审查先行，如本次设计）。K3 不可用 → GLM 架构评审扩展兜底（标注降级）。

## 2. 视觉单点共模防护（Kimi 审查核心新增）

K3 视觉零调用后，视觉链只剩 Qwen 一家，且 Qwen 同时是图的生产者（T3 编码画图）与检查者（视觉官）。错误不是「被漏检」而是可能「被确认无误」。三道防线：

1. **OCR 双读取头**：Qwen vision + PaddleOCR（非 LLM）。关键字段（图内数字/标题）两读不一致 → 升级人工/重渲染。
2. **程序化渲染断言（零 LLM）**：字体嵌入检查、像素非空率、文字区域检测。
3. **种子缺陷图注入回归**：已知缺陷图库（缺字体/标注重叠/数字矛盾）注入视觉检查，漏报即阻断。

**视觉失败回退（显式代价）**：Qwen 重试 ≤2 次 → 人工介入。K3 视觉零调用 = 视觉无模型回退——这是成本指令的显式代价，写进设计而非默认。
