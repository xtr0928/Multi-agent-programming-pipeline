# 设计文档

## 项目结构（树状）
```
.
├── utils.py
└── index.html
```

## 数据模型/接口

### Python 函数接口（`utils.py`）
- `mean(scores: list[float]) -> float`：返回平均分
- `median(scores: list[float]) -> float`：返回中位数
- `pass_rate(scores: list[float]) -> float`：返回及格率（0~1 之间的小数）

### 演示数据（`index.html` 内硬编码）
- 分数列表：`[85, 92, 78, 60, 45, 88, 72, 95, 30, 68]`
- 对应统计结果：
  - 平均分：71.3
  - 中位数：75.0
  - 及格率：0.7（70%）

## 文件清单

### FILE: utils.py
职责：提供平均分、中位数、及格率三个统计函数
依赖: 无
规格：
- 做什么：使用 Python 标准库实现三个纯函数，供导入使用。
- 接口/函数：
  - `mean(scores)`：`return sum(scores) / len(scores)`
  - `median(scores)`：对列表排序后，若长度为奇数取中间元素，若为偶数取中间两元素平均值。
  - `pass_rate(scores)`：`return len([s for s in scores if s >= 60]) / len(scores)`
- 关键逻辑：
  - `median` 需先 `sorted(scores)` 得到有序副本，不修改原列表。
  - `pass_rate` 按 `>=60` 判定及格，返回 0~1 之间的小数。
- 输入输出：输入为数值列表，输出为单个数值。
- 注意事项：
  - 不处理空列表、非数值输入等边界情况（按需求边界）。
  - 不依赖第三方包，仅用标准库。
  - 文件末尾可包含 `if __name__ == "__main__":` 块用于简单自测，但不强制。

### FILE: index.html
职责：静态展示一组写死演示数据的平均分、中位数、及格率
依赖: 无
规格：
- 做什么：纯静态 HTML 页面，内联 CSS 样式，展示演示分数及其三个统计结果。
- 接口/函数：无（静态页面）。
- 关键逻辑：
  - 页面结构：标题 + 演示数据展示区 + 三个统计结果卡片。
  - 演示数据硬编码为 `[85, 92, 78, 60, 45, 88, 72, 95, 30, 68]`。
  - 统计结果可直接硬编码展示（71.3 / 75.0 / 70%），或用少量内联 `<script>` 计算后渲染。
  - CSS 全部内联在 `<style>` 标签中，不引入外部样式文件。
- 输入输出：无输入；输出为浏览器可视页面。
- 注意事项：
  - 不引入任何外部 JS/CSS 框架或资源。
  - 不提供分数输入或动态交互功能。
  - 页面可在浏览器中直接双击打开，无需服务器。
  - 视觉风格简洁清晰，三个统计结果以卡片形式并列展示。
