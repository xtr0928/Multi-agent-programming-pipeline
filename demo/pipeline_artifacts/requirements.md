# 需求文档

## 目标
构建一个极简的学生成绩统计示例：通过 `utils.py` 提供平均值、中位数、及格率三个统计函数，并通过 `index.html` 静态页面使用一组写死的演示数据展示这三个统计结果，技术栈为 Python + 原生 HTML/CSS，无任何框架，不产生多余文件。

## 功能清单
- `utils.py` 提供 `mean(scores)` 函数，接收分数列表，返回平均分。
- `utils.py` 提供 `median(scores)` 函数，接收分数列表，返回中位数。
- `utils.py` 提供 `pass_rate(scores)` 函数，接收分数列表，按 `>=60` 分为及格，返回及格率。
- `index.html` 使用一组写死的演示分数数据，展示平均分、中位数、及格率三个统计结果。
- 页面样式使用原生 CSS，内联在 `index.html` 中，不额外引入样式文件。

## 边界
**做什么**
- 只包含 `utils.py` 和 `index.html` 两个文件。
- `utils.py` 使用 Python 标准库实现，不依赖第三方包。
- `index.html` 为纯静态页面，展示写死演示数据对应的统计结果。
- 统计结果可直接在页面中硬编码展示，或在页面内用简单内联脚本计算，但不得引入外部脚本或框架。

**不做什么**
- 不实现后端服务、API 或前后端交互。
- 不提供分数输入、修改或动态交互功能。
- 不处理空列表、非数值输入、异常数据等边界情况。
- 不额外创建 `style.css`、`app.py`、`README` 等文件。
- 不使用任何前端或后端框架、构建工具、包管理器。

## 技术约束
- 语言：Python 3（仅标准库）。
- 前端：原生 HTML + 原生 CSS，样式内联在 `index.html` 中；如需计算，可使用少量内联 JavaScript，但不得引入外部依赖。
- 文件数量：仅 `utils.py` 和 `index.html` 两个文件。
- 运行环境：`utils.py` 可在任意 Python 3 环境直接导入或运行；`index.html` 可在浏览器中直接打开。

## 交付物清单
- `utils.py`：包含 `mean`、`median`、`pass_rate` 三个函数，使用 Python 标准库实现。
- `index.html`：原生 HTML/CSS 静态页面，内联样式，展示一组写死演示数据对应的平均分、中位数、及格率。
