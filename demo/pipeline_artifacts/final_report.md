## 残留风险与使用说明

### 使用说明
- **`utils.py`**  
  在 Python 3 环境中可直接导入：`import utils`，然后调用 `utils.mean([...])`、`utils.median([...])`、`utils.pass_rate([...])`。

- **`index.html`**  
  双击文件或拖入浏览器即可打开，无需网络、无需服务器。页面为纯静态展示，不支持分数输入或修改。

- **数据一致性**  
  页面展示的统计结果为写死数据对应的结果。如需修改演示分数，必须同步更新页面中硬编码的统计结果或重新计算内联脚本，否则会出现数据与结果不一致的情况。

### 残留风险
- **边界处理**：按需求未处理空列表、非数值输入等异常情况，实际调用时需自行保证输入为合法分数列表。
- **浏览器兼容性**：未进行多浏览器自动化测试，建议在 Chrome、Firefox、Edge 等现代浏览器中打开，显示效果可能存在细微默认样式差异。
- **静态页面限制**：页面无动态交互，不适用于需要用户输入或实时计算的场景。
- **样式维护**：页面样式内联在 `index.html` 中，若需调整视觉风格，需直接修改该文件。
